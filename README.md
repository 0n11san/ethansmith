# Ethan Smith

A tiny, happy landing page for Ethan, age 3: his name in big letters, with a frog, a goggle-wearing yellow buddy, an ice cream cone and a rocket floating around. Tap the characters and they pop. Tap the rocket and it blasts off!

**Live site: https://ethanlsmith.com**

## How it's built

- One file, [`index.html`](index.html): plain HTML, CSS and a few lines of JavaScript.
- All artwork is hand-drawn inline SVG in a flat vector style. There are no images and no build step.
- Hosted on GitHub Pages. The `CNAME` file points the site at `ethanlsmith.com`.

## Updating it

Edit `index.html`, commit and push to `main`. The site updates itself within a minute or two.

To preview locally:

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765.
